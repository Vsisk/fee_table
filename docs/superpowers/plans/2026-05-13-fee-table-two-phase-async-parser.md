# Fee Table Two-Phase Async Parser Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Redesign the fee table parser around code-generated ids, a root-level column pool, path-based category events, and two sequential async LLM calls.

**Architecture:** The parser runs a Column LLM call first to build and close the root column pool, then runs a Category LLM call using that finalized column pool to build the category tree and leaf-column bindings. The reducer consumes raw LLM JSONL events, generates all ids in code, maintains pending events and bracket closure state, and finalizes the section when all detected categories are closed.

**Tech Stack:** Python 3.10+, Pydantic v2, pytest, OpenAI-compatible LLM client, asyncio with synchronous SDK calls wrapped by `asyncio.to_thread`.

---

## Design Summary

- LLM output is raw JSONL. It must not include `event_id`, `target_id`, `parent_id`, category ids, or field ids, except Category LLM may reference finalized root column `field_id` values provided by code in the prompt.
- All real ids are generated by code through `FeeTableIdGenerator`.
- The fee table root owns the region-level column pool: `fee_category_tree.columns: ColumnTerm[]`.
- Non-root parent categories do not own columns.
- Leaf categories keep the existing `columns` field name, but its value becomes `list[str]` of root column `field_id` references.
- Column model changes to `field_id`, `column_key`, `pdf_example`, `pdf_field_name`, `edsl_semi_struct`, `logic_data_node`.
- `logic_data_node.node_name` is the final `column_key`, including any code-generated suffix such as `amount_2`.
- Category LLM emits category structure with `path: list[str]`; code maps path to generated category ids.
- `category_detected` carries `fee_category_type`. `category_type_confirmed` is deprecated.
- Leaf `category_type` is required and must be one of `charge`, `free_unit`, or `financial_fee`. Parent categories must not have `category_type`.
- Category closure uses `category_closed`; `node_finalized` is deprecated. Every explicit `category_detected` must eventually have exactly one `category_closed`.
- Summary, loop, sort, and relation detection are outside this redesign's real LLM scope. Their model fields remain present and empty for structural compatibility.

## Event Protocol

Column LLM allowed raw event types:

```json
{"event_type":"column_detected","payload":{"column_key":"amount","pdf_example":"0.00","pdf_field_name":"Total Amount"}}
{"event_type":"columns_finalized","payload":{}}
```

Column rules:
- `column_key`, `pdf_example`, and `pdf_field_name` are required.
- `column_detected` has no `target_id` and no `parent_id`.
- The first occurrence of a `column_key` keeps that key.
- If the same `column_key` appears with the same `pdf_field_name`, treat it as a duplicate and ignore it.
- If the same `column_key` appears with a different `pdf_field_name`, split it into a new column by assigning the next available suffix: `amount_2`, `amount_3`, and so on.
- After `columns_finalized`, subsequent `column_detected` events are ignored.

Category LLM allowed raw event types:

```json
{"event_type":"category_detected","payload":{"path":["Exceeding package"],"fee_category_name":"Exceeding package","fee_category_type":"parent"}}
{"event_type":"category_detected","payload":{"path":["Exceeding package","INTERNATIONAL ROAMING"],"fee_category_name":"INTERNATIONAL ROAMING","fee_category_type":"leaf","category_type":"charge"}}
{"event_type":"leaf_columns_bound","payload":{"path":["Exceeding package","INTERNATIONAL ROAMING"],"field_ids":["2026051300003001"]}}
{"event_type":"category_closed","payload":{"path":["Exceeding package","INTERNATIONAL ROAMING"]}}
```

Category rules:
- `category_detected` uses only `payload.path` to express parentage.
- `path` is globally unique for explicit category detections. Duplicate explicit path is an error.
- Missing parent paths are auto-created as parent categories and included in the final tree.
- Auto-created parent categories do not need a `category_closed` event. They close automatically when all children are closed.
- Explicit categories must have exactly one `category_closed`.
- `category_closed` uses `payload.path`; if it arrives before the category exists, reducer keeps it pending until category stream end.
- `leaf_columns_bound` uses `payload.path` and root `field_id` references; if it arrives before the leaf exists, reducer keeps it pending until category stream end.
- Leaf categories may close without `leaf_columns_bound`; their `columns` defaults to `[]`.
- Parent categories may have no children and still close.
- Raw event `status` is optional and defaults to `confirmed`. v1 rejects `corrected` and `deleted`.

## Public Model Changes

- `ColumnTerm`:
  - Remove: `seq`, `field_name`, `field_role`.
  - Add: `column_key`, `pdf_example`.
  - Keep: `field_id`, `pdf_field_name`, `edsl_semi_struct`, `logic_data_node`.
- `FeeCategoryInfo`:
  - Add optional `category_type: Literal["charge", "free_unit", "financial_fee"] | None`.
  - Parent validation: `category_type is None`.
  - Leaf validation: `category_type` is required.
- `FeeCategoryTerm.columns`:
  - Root: `list[ColumnTerm]`.
  - Leaf: `list[str]` of root column field ids.
  - Non-root parent: empty list.
- `FeeTableLogicArea`:
  - Keep existing `summary_info`, `loop_info`, and `children_sort_rule` fields empty/null.
  - Do not add warning output for unbound root columns.

- [ ] **Step 4: Implement async scheduler**

```python
class FeeTableCategoryScheduler:
    def __init__(self, provider: FeeTableEventProvider):
        self.provider = provider
        self._lock = asyncio.Lock()

    async def run(self, source_view, reducer):
        column_jsonl = await self.provider.root_columns(source_view)
        async with self._lock:
            reducer.consume_raw_jsonl(column_jsonl, allowed_event_types=COLUMN_EVENTS)
        reducer.ensure_columns_finalized()

        column_pool_json = reducer.column_pool_prompt_json()
        category_jsonl = await self.provider.categories(source_view, column_pool_json)
        async with self._lock:
            result = reducer.consume_raw_jsonl(category_jsonl, allowed_event_types=CATEGORY_EVENTS)
            reducer.finalize_category_stream()

        await self._trigger_mock_enrichment(result.closed_category_ids)
        reducer.finalize_section()
```

The lock is included now so future streaming chunks can mutate reducer safely. v1 has only two awaited LLM calls.

## Validation Rules

- Root category id remains `fee_table_root`.
- Root `columns` contains `ColumnTerm[]`.
- Non-root parent `columns` must be empty.
- Leaf `columns` contains only root column `field_id` strings.
- `column_key` is required and unique after code-side suffixing.
- `pdf_example` is required.
- `pdf_field_name` is required.
- All `edsl_semi_struct` fields remain `""`.
- No real mapping fields are allowed: `data_source`, `expression`, `BO`, `context`, `function`, `resource_id`, XML path, `mapping_tree`.
- Explicit category paths are unique.
- Parent categories must not have `category_type`.
- Leaf categories must have `category_type` in `charge | free_unit | financial_fee`.
- Leaf categories may close with `columns=[]`.
- Parent categories may close with `children=[]`.
- Missing parent paths are auto-created as parent categories and output.
- Auto-created parents do not require `category_closed`.
- Unresolved pending `category_closed` or `leaf_columns_bound` events fail at category stream finalization.
- Unbound root columns are allowed and ignored.

## Acceptance Criteria

- The parser exposes both:
  - `parse_fee_table_logic_area_async`
  - `parse_fee_table_logic_area`

  - root columns

- The reducer does all id generation.
- Existing mock tests are rewritten to raw event semantics.
- `python -m pytest -q` passes with e2e skipped by default.
- Opt-in e2e can run against configured OpenAI-compatible credentials.
